## Receipt tool

BoomerReconcileCheck arguments are:

```
data-directory injector agent stop-file expected-UID preview [--navigate]
```

The default requires the exact dialog already open and allows getters only. Explicit --navigate uses BoomerReceiptNavigation, whose permissions always prohibit Activate, Off, join-option changes and purchases, including when preview=false records a receipt to the supplied ledger. It opens only the guarded event route and returns to base. The final success result is emitted after navigation cleanup and input detach succeed.

Use isolated ledger copies for synthetic pending/uncertain fixtures. Never edit the real operation's status to manufacture a recovery test. Pending entries without sufficient timing/options evidence remain unresolved.
