# Instrumentation and data-access improvements

Updated 2026-10-29, Europe/Malta. Independent source audit, performed without phone commands, detector probes or enforcement experiments. This is an actionable work queue for reducing unnecessary access, instrumentation and retained data. It does **not** promise a lower detection probability: Last Z's actual checks and thresholds remain unknown.

Read [the risk assessment](BOT_DETECTION_RISK_ANALYSIS.md) for the exposure matrix and previously recorded policy evidence. [CURRENT_HANDOFF.md](CURRENT_HANDOFF.md) is authoritative for installed release and live-test status. This file deliberately avoids duplicating a deployment status that another task may be updating.

## What the source establishes

- [`StateProbe`](../tools/last-z-helper/src/dev/codex/lastzhelper/StateProbe.java) opens `/proc/<pinned PID>/mem` read-only, verifies the active process/account and expected game binary, and uses validated manager/field caches. A cold discovery can scan anonymous writable memory up to its time/byte limits. These mechanisms can be local observables; no evidence establishes whether the game checks them.
- [`GameMemory`](../tools/last-z-helper/src/dev/codex/lastzhelper/GameMemory.java) obtains a fresh state snapshot, then opens another read handle for requested Lua fields. Repeated small readers and receipt polls therefore perform repeated identity checks and memory opens. They must not be optimized by weakening identity/focus checks or caching actionable positions.
- [`DeviceInput.action`](../tools/last-z-helper/src/dev/codex/lastzhelper/DeviceInput.java) starts the injector lazily on its first native action and retains one owned session for subsequent actions. ACCESS-03 now lets only the audited Wanted and finished-training collection features defer eager startup until native work is actually required. Every requested action is blocked until the session's initial inspection explicitly confirms a compatible surface. Explicit memory-only training/Wanted inspections and unresolved-operation reporting also avoid injection.
- [`unityBounds`](../tools/last-z-helper/unity-ui.js) temporarily hooks `Canvas.SendWillRenderCanvases` and invokes Unity getters. Successful completion, exceptions and timeouts detach the listener. Scene projection/getter inspection also uses instrumentation; read-only UI previews are not memory-only.
- [`JobRunner`](../tools/last-z-helper/src/dev/codex/lastzhelper/JobRunner.java) bounds `last-run.txt` output to roughly 262 KiB; [`DeviceInput`](../tools/last-z-helper/src/dev/codex/lastzhelper/DeviceInput.java) bounds its session log to 16 KiB and receipt map to 64 entries. These are useful existing limits, not a complete retention policy.
- [`MaintenanceStore`](../tools/last-z-helper/src/dev/codex/lastzhelper/MaintenanceStore.java) saves complete supplied before/after/evidence objects. [`ShareLedger`](../tools/last-z-helper/src/dev/codex/lastzhelper/ShareLedger.java) preserves whole supplied records. Raw data minimization therefore depends on each caller's schema; storage code does not currently enforce a field allowlist.
- [`AutomationController.share`](../tools/last-z-helper/src/dev/codex/lastzhelper/AutomationController.java) previously captured prepared/receipt PNGs for every World share, despite independently verifying exact chat-tile receipts. ACCESS-02 now gates those two PNGs behind an explicit default-off option in source. [`PhoneCheck`](../tools/last-z-helper/src/dev/codex/lastzhelper/PhoneCheck.java) previously captured `before.png` for every injected diagnostic; ACCESS-01 removes that implicit capture. See the current handoff for deployment status.

## Measurement and acceptance rules

Use existing [`Perf`](../tools/last-z-helper/src/dev/codex/lastzhelper/Perf.java) aggregate counters for source/fixture work: memory bytes/read count, field-cache hit/miss, operation duration and callback count. They are disabled in normal runs. Measuring our own resource use is distinct from testing whether an anti-bot system notices us. Do not add detector-state reads, anti-cheat hooks, network fingerprints, “human-like” randomization or evasion experiments.

Every implemented item should record: files changed, source/fixture evidence, whether phone validation was performed, installed version versus source-only status, data fields retained, and any correctness tradeoff. A reduced number of reads/hooks/screenshots is measurable. A reduced probability of enforcement is not established by those measurements.

ACCESS-01 validation on this audit: `python -m unittest discover -s tools/last-z-helper/tests -p test_diagnostic_capture.py -v` passed four tests. All subprocess calls were mocked; no phone command, injection, screenshot, data deletion or game action was performed. No full build/install was performed by this independent task.

ACCESS-02 source inspection: exactly two World share capture calls are guarded by the default-false field/option. The separate attack outcome screenshot remains unconditional. No device/build commands or additional tests were run by this task for this low-impact option; root owns full validation and deployment. Opted-in capture errors retain their existing failure behavior; metadata receipt verification is never replaced by a PNG.

ACCESS-03 validation: `python -m unittest discover -s tools/last-z-helper/tests -p test_deferred_instrumentation.py -v` passed six source-contract checks, and `python tools/last-z-helper/audit_input_positions.py` passed. These verify default-off deferral scope, UID/unresolved ordering, explicit successful compatible hello before send, the persistent rejection gate after a caught failed hello, training compatibility before the attempt journal, and unchanged memory-only action denial. They are not runtime compatibility proof. Root owns full validation and device checks. No metadata eligibility, STOP/focus/account guard, consuming receipt or durable uncertainty rule was relaxed.

No cleanup of existing diagnostics or histories has been performed. Capture opt-in affects future runs only; it does not remove an existing `before.png` or World-share image.
